Dari file desain sampai hasil siap pakai.

Gunakan panduan ini untuk menyiapkan KML/KMZ, memilih output, memantau konversi, memakai ASTRI, dan mengoperasikan modul pendukung EVA tanpa menebak-nebak alurnya.

01

Mulai cepat

Alur standar untuk satu file desain.

  1. 1
    Unggah file desain

    Pilih .kml atau .kmz. Unggah data desain saja; EVA mengambil data ROAD dari server OSM.

  2. 2
    Pilih konfigurasi

    Tentukan cakupan Cluster, Feeder, atau Subfeeder; lalu tipe jaringan AE atau UG dan format output.

  3. 3
    Pilih wilayah bila diminta

    Untuk DXF, HPDB, atau ASTRI, isi Provinsi sampai Postal Code pada popup Pilih Wilayah. Nilai ini ikut menjadi data administrasi output.

  4. 4
    Jalankan proses

    Pastikan tombol Mulai Proses aktif. Baca alasan di bawah tombol jika masih terkunci, lalu jalankan satu job.

  5. 5
    Periksa sebelum memakai hasil

    Cek Ringkasan Hasil, Preview, warning, dan log. Setelah sesuai, unduh output atau lanjutkan workflow ASTRI.

Aturan kerja: jangan membuat job kedua untuk file yang sama saat job pertama masih antre atau berjalan. Pantau dari Monitor Aktivitas.

02

Konversi utama

Arti pilihan pada panel Unggah Data.

Cakupan

Cluster untuk distribution dari FDT ke homepass. Feeder dan Subfeeder untuk backbone dari OLT menuju FDT.

Tipe jaringan

AE untuk aerial/tiang. UG untuk underground/kabel tanam. Pilih sesuai kondisi proyek, bukan hanya berdasarkan nama file.

OutputKegunaanCatatan operasi
DXF (CAD)Gambar CAD hasil konversi.Memerlukan lokasi agar sumber ROAD OSM dan data administrasi mengikuti wilayah proyek. Status bisa terkunci bila fitur DXF tidak diaktifkan.
BOQ (Excel)Bill of Quantity: material, jumlah, dan ringkasan.Pilih saat membutuhkan perhitungan material. Periksa warning BOQ sebelum dipakai untuk proses lanjutan.
ASTRI (Excel)Workbook ASTRI, termasuk data HPDB dan BOQ NRO sesuai output yang aktif.Pilih wilayah lengkap agar nilai administrasi, termasuk postal code, ikut benar.
HPDB (Excel)Master data homepass, FDT, FAT, dan homepass.Gunakan untuk pemeriksaan data homepass dan output database.
KMZ StandarKMZ/KML yang sudah distandardisasi.Untuk mode KMZ Standar tunggal, unggah tepat satu file KML/KMZ. Nama dan struktur diproses memakai rule EVA serta coding FDT aktif.

Multi-output: jika memilih lebih dari satu output, EVA membuat hasil gabungan dalam ZIP. Cek setiap file di dalam ZIP sebelum disebarkan.

03

File desain & struktur folder

Siapkan sumber sebelum mengunggah supaya validasi dan standardisasi tidak menghasilkan placeholder atau warning yang tidak perlu.

File diterima

.kml.kmz
Gunakan satu file desain yang paling lengkap dan terbaru. Jangan memasukkan file ROAD OSM sebagai file desain.

Yang diperiksa

Nama folder, tipe geometri, asset, kabel, FDT/FAT, homepass, serta data pendukung sesuai scope dan tipe jaringan yang dipilih.

Folder tambahan Underground (UG)

Untuk desain underground, gunakan folder duct, handhole, dan aksesori sesuai asset nyata:

SUBDUCT 32/28 SUBDUCT 40/34 TALI PANCING NEW HH 40X40X60 NEW HH 80X80X130 T-WAY.

Masukkan line, HDPE, dan drop wire ke SUBDUCT 32/28 bila itu struktur proyeknya. Jangan membuat folder alternatif hanya untuk variasi penamaan.

Feeder & Subfeeder

Backbone biasanya membutuhkan OLT, JOINT CLOSURE, folder pole, CABLE, dan SLACK HANGER. Folder UG tetap mengikuti tipe asset: duct, handhole, serta aksesori.

Gunakan scope Feeder/Subfeeder hanya bila isi file memang jalur backbone; jangan memaksakan file cluster ke scope backbone.

Jangan tertipu nama folder kosong: folder yang ada tetapi tidak memiliki placemark/geometri yang benar bukan data asset yang valid. Periksa isi folder, bukan hanya namanya.

04

Wilayah, postal code, dan ROAD OSM

Lokasi dipakai untuk output administrasi serta pemilihan sumber jalan.

  1. Pilih Provinsi, lalu Kota/Kabupaten, Kecamatan, Kelurahan, dan Postal Code dari popup Pilih Wilayah.
  2. Pilih Area ASTRI bila tersedia dan relevan dengan pekerjaan.
  3. EVA mencoba ROAD OSM tingkat kecamatan terlebih dahulu. Bila file tidak tersedia, EVA menggunakan ROAD tingkat provinsi sebagai fallback.
  4. Pastikan nilai yang dipilih memang lokasi proyek; nilai ini ikut ke Excel HPDB/ASTRI.

Perilaku penting: popup wilayah wajib muncul untuk DXF, HPDB, dan ASTRI. Untuk KMZ atau BOQ saja, popup wilayah tidak diperlukan.

05

Pantau, validasi, lalu unduh

Job selesai bukan berarti hasil otomatis siap dipakai.

Ruang Hasil

Lihat status proses, nama file output, ringkasan, dan tombol unduh. Anda dapat menyesuaikan nama file sebelum unduh bila field tersedia.

Preview

Gunakan tab map, BOQ, HPDB, DXF, warning, statistik layer, dan log untuk memastikan hasil sesuai sumber.

  1. Tunggu status job sampai selesai; jangan refresh lalu submit ulang hanya karena progress belum berubah beberapa saat.
  2. Buka Ringkasan Hasil. Cocokkan jumlah asset, warning, dan output yang dipilih.
  3. Buka Preview. Untuk BOQ/HPDB, cek tabel dan warning. Untuk DXF/KMZ, cek struktur/preview yang tersedia.
  4. Baca Log Proses jika ada error atau mapping/folder yang tidak sesuai.
  5. Unduh hasil hanya setelah preview dan warning sudah diterima atau diperbaiki.

Output hilang atau tidak siap: buka Monitor Aktivitas untuk melihat job asli. Jika file hasil sudah kedaluwarsa atau tidak tersedia, jalankan ulang setelah memperbaiki sumber/konfigurasi; jangan menganggap file lama masih valid.

Shortcut: Ctrl + Enter mulai proses, ? bantuan singkat, Ctrl + H Monitor Aktivitas, Esc tutup modal/drawer.

06

Workflow ASTRI

Panel ASTRI dipakai untuk mencari pekerjaan, mengambil APD, upload, verifikasi, approve schedule, dan BOQ sesuai hak akses.

  1. 1
    Login ASTRI

    Masukkan akun ASTRI pada panel DRM APD. Logout ketika sesi tidak lagi digunakan.

  2. 2
    Cari data pekerjaan

    Pilih target Cluster/Subfeeder/Feeder, filter status, masukkan kode atau nama, lalu tekan Search. Pilih work order yang benar dari daftar hasil.

  3. 3
    Cocokkan dengan EVA

    Tekan Cari Match ASTRI untuk mengikat pilihan ASTRI dengan konteks EVA. Search berarti mencari data ASTRI; Cari Match berarti memakai pilihan tersebut untuk action berikutnya.

  4. 4
    Siapkan dokumen

    Convert dari APD ASTRI mengambil dokumen APD lalu menyiapkan hasil EVA. Alternatifnya, gunakan hasil konversi yang sudah diperiksa dari panel utama.

  5. 5
    Upload dan Verify

    Upload dokumen setelah preview EVA benar. Lakukan Verify hanya setelah dokumen dan data benar-benar siap.

  6. 6
    Schedule lalu BOQ

    Approve Schedule dan Add BOQ adalah perubahan nyata di ASTRI. Pastikan WO, vendor, supplier per item, permit, dan preview sudah benar sebelum submit.

08

Troubleshooting cepat

Cek penyebab yang paling umum sebelum mengulang job.

  • Tombol Mulai Proses masih terkunci.Pastikan file KML/KMZ sudah dipilih, minimal satu output dipilih, scope/AE-UG benar, dan popup wilayah telah diisi bila output DXF/HPDB/ASTRI dipakai. Baca teks alasan di bawah tombol.
  • Folder atau asset tidak terbaca.Periksa nama folder, isi placemark, dan tipe geometri. Folder kosong bukan pengganti asset. Pilih scope yang sesuai dengan isi file.
  • Nama/kode memakai XXX.Data Coding FDT yang diperlukan belum ditemukan atau belum cocok. Periksa Coding FDT dan OLT mapping, lalu ulangi konversi jika output harus memakai kode final.
  • ROAD OSM tidak sesuai atau tidak tersedia.Periksa pilihan Provinsi/Kota/Kecamatan pada popup Wilayah. EVA memakai kecamatan bila tersedia dan fallback ke provinsi bila tidak ada file kecamatan.
  • Job lama di antrean atau gagal.Buka Monitor Aktivitas dan log job. Jangan langsung submit ulang; identifikasi error file, folder, konfigurasi, atau worker terlebih dahulu.
  • ASTRI tidak bisa menjalankan action.Login ulang bila sesi berakhir, Search lalu pilih work order yang benar, lakukan Cari Match ASTRI, dan refresh status sebelum action yang bergantung pada WO.
  • Upload ASTRI sudah dilakukan tetapi versi tidak sesuai.Download/verify daftar dokumen terbaru dan cocokkan filename, waktu, serta isi file. Upload menghasilkan versi tambahan, bukan penggantian dokumen lama.
09

Istilah & referensi teknis

Istilah yang muncul di EVA dan output engineering.

AE
Aerial: jaringan melalui tiang/udara.
UG
Underground: jaringan kabel tanam, duct, handhole, dan aksesori bawah tanah.
FDT
Fiber Distribution Terminal: titik distribusi utama jaringan.
FAT
Fiber Access Terminal: titik akses/distribusi menuju homepass.
HPDB
Homepass Database: data cluster, FAT, dan homepass dalam workbook Excel.
BOQ
Bill of Quantity: daftar material dan kuantitas pekerjaan.
APD
Dokumen sumber desain dari ASTRI yang dapat diproses melalui EVA.
ROAD OSM
Data jalan OpenStreetMap yang disediakan server EVA berdasarkan wilayah terpilih.

Untuk integrasi teknis: spesifikasi endpoint tersedia sebagai OpenAPI YAML. Dokumen ini fokus pada cara pakai aplikasi, bukan kontrak API.
