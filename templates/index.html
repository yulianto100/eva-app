    Panduan EVA

    Cara pakai cepat dan struktur folder yang dibutuhkan.

    Cara pakai
    1. Unggah file .kml atau .kmz untuk data desain.
    2. Untuk DXF, HPDB, atau ASTRI, pilih wilayah pada popup sebelum proses dimulai. ROAD OSM dipilih otomatis.
    3. Pilih cakupan, tipe jaringan, dan format output.
    4. Lihat checklist untuk memastikan konfigurasi sudah lengkap.
    5. Klik Mulai Proses untuk menjalankan konversi.
    6. Unduh hasil setelah proses selesai.
    Folder KML/KMZ standar

    Sistem mendeteksi folder ini secara otomatis. Folder tertulis tebal wajib ada.

    Istilah teknis
    • BOQ - Bill of Quantity, daftar material dan jumlahnya.
    • HPDB - Homepass Database, master data homepass per cluster.
    • ASTRI - Workbook standar dari ASTRI yang merangkum HPDB + BOQ NRO.
    • FDT - Fiber Distribution Terminal (titik distribusi utama).
    • FAT - Fiber Access Terminal (titik akses ke homepass).
    • NRO Cluster - Sheet ringkasan material per cluster.
    • AE / UG - Aerial (di tiang) atau Underground (tanam).
